---
title: "Installing Tableau Public"
permalink: /tableau/software-setup/
---

To participate in the workshop, you must install **Tableau Public** before arriving.

> **Current Version:** As of February 12, 2026, the current version of Tableau Public is **2025.3.2**.  
> Please install the most recent available version at the time of download.

---

### Step 1: Go to the Tableau Public Website

Visit: https://public.tableau.com

On the homepage, select:

**Create → Download Tableau Desktop Public Edition**

---

### Step 2: Create a Tableau Account

You will be prompted to create a free Tableau Public account.

- Enter your email address  
- Create a password  
- Confirm your registration  

> **Important:** Please make note of your username and password.  
> You will need these credentials to publish dashboards to your Tableau Public profile during the workshop.

---

### Step 3: Download and Install

After creating your account:

1. Download the installer for your operating system (Windows or macOS).
2. Open the downloaded file.
3. Follow the installation prompts to complete setup.

---

### Step 4: Verify Installation

Once installed:

- Open Tableau Public.
- Sign in using the account you created.
- Confirm the software launches without errors.

---

### IT Permissions Notice

If you are using a government, university, or employer-issued laptop, you may need IT authorization to install software.

Please request any necessary permissions **well in advance of the workshop** to avoid delays. If installation is not possible on your device, contact the instructor as soon as possible so alternative arrangements can be explored.
