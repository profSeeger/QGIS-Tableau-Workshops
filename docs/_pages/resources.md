Expand your skills beyond our workshops with these curated resources. Whether you're just starting out or looking to deepen your expertise, these tutorials, guides, and communities will support your learning journey.

## QGIS Resources

### Official Documentation
- [QGIS Training Manual](https://docs.qgis.org/training_manual/) - Comprehensive official tutorial covering all QGIS basics
- [QGIS User Guide](https://docs.qgis.org/latest/en/docs/user_manual/) - Complete reference documentation
- [PyQGIS Cookbook](https://docs.qgis.org/latest/en/docs/pyqgis_developer_cookbook/) - Python programming for QGIS automation

### Video Tutorials
- [QGIS Uncovered](https://www.youtube.com/c/QGISUncovered) - Steven Bernard's excellent video series
- [Klas Karlsson YouTube Channel](https://www.youtube.com/c/KlasKarlsson) - Great tutorials for all skill levels
- [GIS Tutorial YouTube Playlist](https://www.youtube.com/playlist?list=PLNBeueOmuY163iwu4VpZdjqqdU1HkRTP_) - Organized learning path

### Written Tutorials & Blogs
- [QGIS Tutorials and Tips](https://www.qgistutorials.com/) - Ujaval Gandhi's excellent step-by-step tutorials
- [Free and Open Source GIS Ramblings](https://anitagraser.com/) - Anita Graser's blog with advanced techniques
- [North River Geographic](https://www.northrivergeographic.com/qgis) - Practical GIS tutorials
- [Open Source Options](https://opensourceoptions.com/blog/) - GIS and remote sensing tutorials

### Sample Data Sources
- [Natural Earth](https://www.naturalearthdata.com/) - Free vector and raster map data
- [USGS Earth Explorer](https://earthexplorer.usgs.gov/) - Satellite imagery and elevation data
- [OpenStreetMap](https://www.openstreetmap.org/) - Collaborative mapping data
- [QGIS Sample Data](https://qgis.org/en/site/forusers/download.html#sample-data) - Practice datasets

### Community & Support
- [QGIS Community](https://qgis.org/community/) - Official community resources
- [GIS Stack Exchange](https://gis.stackexchange.com/) - Q&A for GIS professionals
- [r/QGIS on Reddit](https://www.reddit.com/r/QGIS/) - Active community discussions

## Suggested Learning Paths

### Complete Beginner Path
1. Take our intro workshops (QGIS or Tableau)
2. Complete official tutorials for your chosen tool
3. Practice with sample datasets
4. Join online communities for support
5. Work on a personal project to apply skills

### Intermediate Path
1. Review workshop materials
2. Complete advanced tutorials from resources above
3. Participate in challenges (Makeover Monday, 30 Day Map Challenge)
4. Read books on data visualization principles
5. Consider certification programs
