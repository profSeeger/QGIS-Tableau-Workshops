## Software Setup

### Tableau Desktop vs. Tableau Public

**For this workshop, we'll use Tableau Public** - a free version of Tableau that includes all core functionality. The main difference is that workbooks are saved to the Tableau Public cloud (publicly visible).

**Already have Tableau Desktop?** That works too! The workshop applies to both versions.

### System Requirements

- **Operating System:** Windows 10/11 (64-bit) or macOS 10.15+
- **RAM:** Minimum 8GB (16GB recommended for large datasets)
- **Disk Space:** 15GB free space
- **Display:** 1366x768 minimum resolution (higher recommended)
- **Internet:** Required for downloading and for Tableau Public

### Installation Instructions

#### Download Tableau Public

1. Visit: [https://public.tableau.com/app/discover](https://public.tableau.com/app/discover)
2. Click "Download the App" or "Create a Free Account"
3. Create a free Tableau Public account (required)
4. Download the installer for your operating system

#### Windows Installation

1. Run the downloaded `.exe` installer
2. Follow the installation wizard
3. Sign in with your Tableau Public account
4. Launch Tableau Public from the Start menu

#### macOS Installation

1. Open the downloaded `.dmg` file
2. Drag Tableau Public to your Applications folder
3. Launch Tableau Public
4. Sign in with your Tableau Public account

### Verify Installation

1. Open Tableau Public
2. You should see the start page with sample data connections
3. Try opening one of the sample workbooks to confirm everything works
